# 🤖 Sentinel AI: User Commands Guide

Welcome to the Sentinel AI command reference. Access to these commands depends on your subscription tier (**Core** or **Quantum**).

---

## 🟢 Public Commands
*Available to everyone.*

| Command | Description |
| :--- | :--- |
| `/upgrade` | Information on how to access Core and Quantum premium tiers. |

---

## 🔵 Core Tier Commands
*Includes all Public commands.*

| Command | Description |
| :--- | :--- |
| `/price [coin]` | Check real-time simulated price for major assets (BTC, ETH, SOL, etc.). |
| `/feargreed` | View the current Fear & Greed Index to gauge market sentiment. |
| `/summary` | Read the latest **Daily Macro Bias** report (Zero-cost cached data). |
| `/levels [coin]` | Show technical support and resistance levels for the day. |

---

## 🟣 Quantum & Lifetime Tier Commands
*The ultimate institutional experience. Includes all Core & Public commands.*

| Command | Description |
| :--- | :--- |
| `/ai_scan [coin]` | **On-Demand Deep AI Analysis.** Real-time scan using Sentinel AI. |
| `/vip_analysis` | Read the latest **Quantum Deep Dive** (Persistent institutional cache). |

---

> [!TIP]
> **Pro-Tip**: Use `/summary` and `/vip_analysis` to get instant insights without consuming your daily AI quota. These reports are generated automatically by Sentinel AI every morning.
